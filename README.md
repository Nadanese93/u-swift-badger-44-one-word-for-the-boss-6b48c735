## The entry

**Neckbreather** — one word for the boss who is always right behind you,
breathing down your neck. No phrase, no caption, no explanation: the word
is the whole entry.

## How it works

`main.py` (Python 3, standard library only) reads `entry.txt` and writes it
byte-identical to `/output/entry.txt`. It enforces the contest gate locally
before writing: the entry must be 1–30 characters, exactly one word, and not
only white space — otherwise it raises `ValueError`.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
